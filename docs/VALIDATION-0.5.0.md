## 手机状态与剩余限制

2026-10-18 用户重新开启无线调试后，已连接荣耀 Magic8（BKQ_AN00），备份 Movelet 应用数据库至本机忽略目录 `deliverables/personal/upgrade-0.5/before/`，随后使用保留数据的覆盖安装，结果为 `Success`。安装包 SHA256 与上表个人版一致；手机确认 `versionCode=5`、`versionName=0.5.0-personal`，启动命令返回 `Status: ok`。没有卸载或清除手机应用数据。

启动后界面读取返回了无关应用的内容，因此停止界面操作，不把它作为 Movelet 编辑入口的真机验证证据。自动审批审查随后拒绝了升级后再次导出数据库，理由是界面证据存在应用身份歧义，继续读取可能超出授权范围；没有绕过或继续导出。升级前后数据一致性核对和完整真机编辑流程仍未完成，不能将安装/启动成功视作完整真机验收。

每周安排逐日保存，不支持一键复制整周或跨分区拖拽；候选动作仍不能加入训练。模板并非历次版本档案，过去训练以已保存的训练快照为准。数据导出、长期耗电与长期稳定性验证不在本轮范围内。
