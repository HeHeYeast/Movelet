2026-10-16。全部 24 个动作配图已接入；23 幅双格图与 1 幅四格图，共 50 个阶段画面。生成、返工和可见要点审核见 [全库审核记录](GENERATED-IMAGE-REVIEW-0.4.md)。素材审核不是临床或真人教练签核。

## 构建与测试

- 个人版和公开版均完成 `testDebugUnitTest`、`lintDebug`、`assembleDebug`、`assembleDebugAndroidTest`。
- 两版单元测试各 20 项通过：训练逻辑 16、Room 持久化 2、媒体完整性 2。媒体测试确认 24 个动作各有一幅生成图，实际解码尺寸与文件 SHA256 对应台账；公开版不含第三方个人原图。
- Lint：0 错误，11 个已有的依赖更新建议警告。
- API 35 模拟器个人版、公开版各 3 项交互测试通过（分别 16.205 秒、15.149 秒）：24 个动作逐个搜索并打开，等待各自图片实际加载；四格图阅读顺序；缩放与返回；完成训练组、暂停教学与记录保存。个人版另验证 AI/原图切换及分页。
- 实际查看个人版动作库、徒手深蹲、肩胛轻收、改良波比跳截图：统一缩略图、双格/四格图完整比例、文字与阅读顺序正常；长页面可滚动。
- 新增全库测试首次发现搜索框与动作卡片的同名文字定位冲突；限定非输入框后重跑通过。这是测试定位问题，不是图片加载问题。
- APK 包检查：个人版 60 张（24 生成 + 36 原图），公开版 24 张，实际文件与台账逐字节校验一致。
- 未修改训练剂量、进阶规则或 Room schema。候选动作 `wall_slide / split / step_jack / burpee` 仍排除默认计划。

日志与公开版单元测试 XML：`deliverables/validation-0.4.0/`；个人 XML 与模拟器截图在本机 `deliverables/personal/` 下。构建工具链仍为项目固定的 JDK 17、Gradle 8.11.1、SDK 35。

## 手机与安装

本轮尚未将 0.4.0 覆盖安装到荣耀 Magic8。前一轮 0.3.0 安装曾被手机系统以 `User rejected permissions` 拒绝，不能把模拟器通过当作新版真机验收。没有清除手机数据。

将个人 APK 传到手机，用文件管理器打开，允许该来源安装应用，然后覆盖安装；不要先卸载旧版。卸载或清除数据会删除训练记录。完整真机流程、耗电与长期稳定性仍待验证。

## 仍有的限制

- 所有动作已有配图，但生成图不等于真人示范，不能证明真实发力或个体适用性。
- 4 个候选动作仍待进一步专业复核；来源中康复人群与训练剂量没有直接搬入本 App。
- 数据导出、训练视频、长期真机验证未在本轮实现。
