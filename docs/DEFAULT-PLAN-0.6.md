每日均先安排以下五项，均为 1 组：

| 动作 | 每组目标 |
|---|---|
| 下巴微收 | 8 次 |
| 小幅猫牛式 | 8 次 |
| 穿针引线 | 每侧 5 次 |

- 图中范围从下限开始：俯卧撑 6–8 次先取 6；平板 20–30 秒先取 20；周六有氧 1–2 组先取 1。可在编辑页自行调高或减量。
- 有氧继续遵循先前的少量、可选原则，全部默认关闭，不开启也能完成必选训练。
- 周六保留图中的主训练组数，没有擅自减半；“轻量”表示控制强度，不追求力竭。相邻日期含重复肌群，用户可按疲劳减量或休息，App 不把此编排宣称为个体化评估后的处方。
- 周日“走动 / 拉伸”先落实为走动 3 分钟；周一说明中的 3–4 分钟泛称放松未另造具体动作，可自行按需安排。
- 保留扶椅提踵的稳固支撑、猫牛小幅版本；其余缺少的具体动作均新增独立 ID，不用不同姿势的旧图片代替。
- 参考图的“约25分钟”和“肩背约6分钟”不是精确计时保证；按实际速度、休息和完成量记录时长。既有渐进规则与简化训练逻辑不变。

## 数据兼容和记录单位

默认计划解析仍是：具体日期修改 → 每周自定义模板 → 内置默认。此次仅更换最后一层；已保存的自定义安排和训练快照不重写。若某天已有自定义覆盖，先在当天编辑页“恢复每周安排”；若每周模板也自定义过，再恢复对应星期的默认安排。

门框新增 `SECONDS_EACH_SIDE`（秒/侧），每组实际记录按单侧秒数；旧 `SECONDS`、`EACH_SIDE` 与 `REPS` 不变。仅轻松走动放宽到最多300秒，其他计时动作仍最多120秒。数据库保持 Room v2，没有数据库迁移。
