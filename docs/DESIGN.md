# 轻练 Movelet · 第一轮方案

## 目标与边界
为本人荣耀 Magic8 开发原生离线 Android App。Kotlin、Compose Material 3、Room；无账号、无服务器、无网络权限、不接入分析 SDK，禁止系统云备份。最低 Android 8，编译/目标 API 35；MagicOS 具体兼容性需真机验证。

当前目录无旧项目，对话未提供旧周计划完整表，不能声称完成了对旧表的逐项审查。以下为依据明确原则建立的新初始方案。训练建议用于习惯养成，不是诊断、康复处方或疗效承诺。

## 信息与视觉设计
- 今日：日期标题 → 七日选择 → 今日概要及进度 → 固定肩背活动 → 力量/恢复 → 可选有氧 → 底部开始/继续按钮。非今日只能浏览与调整，不能为过去或未来记入训练。
- 详情：动作分类与难度 → 教学素材状态/专业原文入口 → 起始姿势 → 编号步骤 → 呼吸 → 常见错误 → 安全提示 → 降阶/进阶 → 来源及授权。附件仅参考信息层级，不复制未授权图片。
- 专注：大字号动作名、目标次数/秒数、当前组，主要操作放底部；完成一组、跳过当前动作、休息/跳过休息、暂停、教学、简化、提前结束。进入后台自动暂停，返回后手动继续；每组与计时写入本地。
- 动作库：中文/英文搜索，功能/部位分类与难度筛选。无网络仍可阅读文字。
- 记录：一周日历、真实组数、实际次数/时长、完成/部分/简化标识。零组结束不冒充完成，不预置虚假数据。

颜色：暖白 #F6F7F2、松绿 #276553、浅绿 #E3EBD8、杏色提示 #FFF0DC；圆角 20–28dp；系统中文字体、正文 16sp、主要操作 56dp、最小点击区域 48dp。装饰采用抽象几何分类符号，明确不作人体姿势教学。支持系统深色、字体缩放、安全区域、纵向滚动。

## 初始周计划
每天肩背轻活动约 5–7 分钟：颈部轻转每侧 3 次（每次约 5 秒）、坐姿胸椎转动每侧 5 次、肩胛轻收 8 次、坐姿展胸 3×15 秒。余时用于自然呼吸、换姿和舒适范围内慢做，不能为了凑时长反复拉伸。

| 日 | 内容 | 初始剂量 |
|---|---|---|
| 周一 | 全身 A：斜板俯卧撑、徒手深蹲、臀桥、死虫 | 各 2 组；6 / 8 / 10 / 每侧 5 次 |
| 周二 | 恢复：轻松踏步、可选小幅穿针引线 | 6–15 分钟，无高负荷 |
| 周三 | 全身 B：斜板俯卧撑、椅子坐站、俯卧 W、鸟狗 | 各 2 组；6 / 8 / 6 / 每侧 5 次 |
| 周四 | 恢复与活动 | 6–15 分钟 |
| 周五 | 全身 A | 同周一，不自动加量 |
| 周六 | 轻活动：坐站、提踵、踏步 | 各 1 组，可跳过 |
| 周日 | 恢复与每周回顾 | 约 6–10 分钟 |

力量日预算约 20–25 分钟（含教学、组间休息与换姿），不是强制时长。组间默认 60 秒，可延长；活动组默认 20 秒。每组保留约 2–4 次余力，无法稳定完成即降阶/减次数。标准俯卧撑先作为可替换选项，考虑本人 6–15 次能力与未经评估的肩痛，默认从更易控制的稳定高台版本开始。有氧默认关闭，最多轻量 2×30 秒；开合跳及无跳跃波比仅在库中，不默认安排。

俯卧 W 是低负荷肩胛控制练习，不能替代足够阻力的拉类力量训练。纯徒手上背负荷有限，当前明确保留这个限制；不使用不可靠的门框/桌底悬挂方案。

疼痛策略：出现关节痛、刺痛或动作使症状加重，停止该动作；选择不引发疼痛的替代或结束。持续/加重、明显无力麻木或活动受限需专业评估；突然剧痛、外伤后变形/不能活动等及时就医。不得把痛感当作进步。

渐进策略：训练结束记录“轻松/适中/吃力”和是否疼痛。最近两次同类力量训练完整完成、无痛且均轻松时，仅展示“下次可为一个动作每组加 1 次”的建议，由用户调整；不自动跨级、不同时增加组数与次数。恢复/部分/简化记录不触发加量。

## 架构与数据
单 Activity，Compose + ViewModel 单向数据流；纯 Kotlin 训练引擎独立测试。无需 Hilt/服务器。
- Exercise：独立 JSON 资源，ID、中英文名、类别、肌群、难度、剂量/计数单位、步骤、呼吸、错误、风险、降进阶、来源、素材路径及授权状态。
- DayPlan：按真实日期持久化的动作实例，引用 Exercise ID，包含组数、次数/秒数、段落、是否可选；与库分离。
- Workout：UUID、真实开始日期、开始/结束时间、计划快照、各动作完成剂量/跳过状态、有效计时、休息秒数、暂停状态、反馈。快照保证之后修改计划不改历史。
- Room：计划表、训练表，schema 导出；事务约束仅一场进行中的训练。无 destructive migration。JSON 快照结构版本固定为 1，后续升级须迁移。

第一轮素材策略：专业网页只作为可打开的原始教学来源。未获图片/视频再分发授权的内容不打包、不热链、不用 AI 人体图替代；本地素材路径为空，授权状态逐项记录。文字为独立中文重述，四个重点动作先核查动作要点；仍需真人专业复核及取得离线高清素材授权，才能宣称完整教学素材交付。

## 验收
单元测试覆盖周计划负荷分布、跳过不算完成、简化不删除已完成组、次数边界、休息与暂停、进阶门槛、数据关联和双侧计数。Room 测试覆盖关闭重开后的记录/计划和单活动训练约束。构建 debug APK 并检查清单与签名。若有可用 Android 设备/模拟器则安装运行并验证导航、完成组、恢复、筛选和历史；未连 Magic8 不称真机测试完成。
