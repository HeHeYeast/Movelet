## 剩余限制

- 新增 8 项暂缺配图，按用户确认先采用文字教学和资料链接。
- 图片和文字没有真人专业签核；参考图不是个体化运动处方。旧四个候选条目保持原限制。
- 有氧默认关闭；周六按照图保留主训练组数。约 25 分钟为安排目标，实际用时取决于动作速度和休息。
- 用户数据导出、长期耗电与稳定性验证仍待后续。
